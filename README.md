# DigiCanji v1.19.0

手書き認識を利用した漢字学習アプリと、配布用クイズHTMLを生成するエディターです。

## v1.19.0 混合表記の小書き・1文字なぞり書き

- 「散った」「失った」「買った」など漢字と平仮名が混ざる書き問題でも、現在の解答位置が「つ／っ」「や／ゃ」など同じ大小ペアのかなである場合に限り、小書きの配置判定を適用します。横書きは左下1/4、縦書きは右上1/4という従来の基準と閾値をそのまま使います。
- 対象を現在位置の同じ大小ペアだけに限定し、漢字候補の順位、字形比較、端末内漢字補助探索には変更を加えていません。v1.18.1で安定した漢字認識品質を維持します。
- 見直しの「なぞり書き」は、答え全体を小さく並べるフリー枠から、1文字を手書きパッドいっぱいに表示して順番に進む方式へ変更しました。認識結果は文字ごとに確認でき、「次の字」「完了」で進みます。
- なぞり書きは正誤にかかわらず次の文字へ進める従来どおりの優しい練習方式です。
- 問題データ800問、エディター内プレイヤーとの一致、内蔵認識自己試験73ケースを確認しています。

## v1.16.0 小書き判定・筆跡表示改善

- 小書きかなは、縦書きではマス右上1/4、横書きでは左下1/4に筆跡の中心線がおおむね収まる場合を最も強い判定根拠にします。中央境界のごく小さなはみ出しは許容しつつ、90%以上の筆跡が正しい1/4にあることを確認します。
- 上記の1/4条件を満たす場合は、外部認識器が「や・ゆ・よ・つ・う・か」など通常サイズを返しても、対応する小書き字を優先します。面積だけでは小書き化しません。
- 読み候補の順位付けでも、1/4内に収まった入力に対して通常サイズ候補への減点を強め、大小判定の揺れを抑えます。
- 手書き線は一般的なパッド寸法で従来より約1〜2 CSS px細くしました。認識器へ渡す中心線座標や画数判定は変えないため、認識精度を犠牲にせず細部・交差位置を見やすくします。
- なぞり書き側も同じ線幅係数を使用し、通常回答との書き味をそろえます。

## v1.6.0の認識改善

### 実画数を基準にした完成判定

一文字枠では、曲がり角を別画へ自動分割して不足画を補う処理を停止しました。漢字・かなは実際に筆を離した画数を基準に判定します。偶発的に一画が分かれた場合は結合補正、微小タップはタップ除外で救済します。

### 候補字形との一般化比較

認識器が返した漢字候補を、端末で表示可能な教育向け標準字体へ描画し、入力筆跡と正規化して比較します。双方向距離、領域分布、縦横投影を組み合わせ、画数だけが一致する未完成字や、部品の突出・欠落が大きい候補を減点または拒否します。特定の漢字名を列挙せず、すべての一文字漢字候補へ同じ処理を適用します。

### 修正方針

- 一文字モードでは筆画分割による救済を使用しない
- 認識候補の順位・画数・部品規則に、字形適合度を追加
- 字形比較は低解像度の骨格モデルをキャッシュし、端末負荷を抑制
- 診断記録へ字形得点、被覆率、拒否理由を保存

## v1.5.0から継続する回答方式

### 全問題を1枠1文字へ統一

書き問題だけでなく、読み問題も1枠1文字で認識します。通常の問題では文字列全体を一度に認識しないため、縦書きで起きていた文字順の入れ替わり、文字数の増減、濁点の所属先の誤判定を回避できます。

### 常に10枠を表示

正答の文字数に関係なく、すべての問題で10枠を用意します。正答長から送り仮名を推測できません。未入力の末尾枠は採点時に無視し、余分な文字を入力した場合は不正解になります。

### 正方形のスクロール式認識欄

- 横書きレイアウト：正方形枠を横1列に並べ、横スクロール
- 縦書きレイアウト：正方形枠を縦1列に並べ、縦スクロール
- 枠のクリック・タップ、矢印キーで選択
- 選択した枠は自動的に表示範囲へ移動

## 認識処理

- 読み問題では、カタカナ候補をひらがなへ正規化します。
- 読み問題では、1文字のひらがな候補だけを採用します。
- 書き問題では、漢字・かなを含む1文字候補を従来どおり画数・構造・認識器間一致で評価します。
- 通常認識が確実な場合は外部再認識を行わず、通信と処理を抑えます。

## 問題データ

```text
前部,問部,後部,解答,解説
```

- 最大1000問
- 1回の出題は最大10問、重複なし
- 正答率が低い問題と未出題問題を優先する重み付きランダム
- 問部と解答が同一、または解答にひらがな・漢字以外を含む場合はエラー

## 認識診断モード

公開URLの末尾に `?recognitionDebug=1` を付けると、設定画面に「認識診断」が表示されます。

端末内に最大80件まで、筆跡、各認識器の候補、得点、拒否理由、画数、使用可能フォントなどを保存できます。診断JSONは自動送信されません。
